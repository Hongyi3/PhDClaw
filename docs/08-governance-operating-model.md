# Governance Operating Model

## Maintainer cadence

- weekly triage
- milestone review every two weeks
- release readiness review before any public tag

## Documentation rule

Major decisions should be recorded in `plans/documentation.md` and then summarized into the relevant long-lived docs if they affect architecture, scope, or public behavior.

## Community channels

Use GitHub Issues for actionable work and GitHub Discussions for open-ended design, onboarding, and community requests.
