# Journal Strategy

## Primary software-paper target

### JOSS
Use JOSS as the first formal software-paper target because it rewards open-source research software with a clear statement of need and public review.

## Secondary target

### Bioinformatics Application Note
After v1.0 and initial external use evidence, prepare a short software note positioned around practical bioinformatics utility, free availability, and implementation clarity.

## Preparation work

- keep the related-work section current from day one
- maintain a strong statement of need
- preserve benchmark artifacts and exemplar outputs
- keep AI usage disclosure explicit
- maintain install and validation documentation continuously
