# Codex Working Plan

## Why this repo is Codex-friendly

Codex works best when the repository contains:

- a clear `AGENTS.md`
- explicit issue-sized tasks
- stable source-of-truth plan files
- validation commands
- reusable skills for recurring work

## What Codex should handle first

1. schema package creation
2. evidence graph package creation
3. Quarto template generation
4. policy-check package scaffolding
5. release-engine scaffolding
6. exemplar-project assembly

## What should stay human-led initially

- branding and public narrative
- scope changes
- journal targeting decisions
- licensing changes
- policy interpretations
