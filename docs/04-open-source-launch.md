# Open-Source Launch Plan

## Release philosophy

Launch with a package that already looks and behaves like scholarly infrastructure.

## Must-have repository features

- `CITATION.cff`
- `codemeta.json`
- `LICENSE`
- `SECURITY.md`
- `CODEOWNERS`
- issue forms
- pull request template
- CI
- Dependabot
- CodeQL
- Scorecard
- governance and contributor docs

## Launch assets

- polished README
- docs site or docs-ready content
- three exemplar studies
- archived DOI-backed release
- software paper draft
- benchmark documentation

## Launch sequence

1. freeze scope
2. validate exemplar workflows
3. cut release candidate
4. archive release
5. publish docs
6. submit software paper
7. recruit early external users
