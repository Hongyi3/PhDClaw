# Product Thesis

ClawBio Scholar should not be a generic academic chatbot.

It should be a **research operating system** for biomedical and computational-biology PhD work that turns inputs into defensible research objects.

## Primary job to be done

Help a doctoral researcher go from literature, data, and ideas to:

- a reproducible workflow
- provenance-complete figures
- manuscript-ready outputs
- citable software and release artifacts

## Strategic focus

Start narrow:

- computational biology
- bioinformatics
- biomedical data science
- omics-heavy, workflow-heavy doctoral work

Do not expand to all academic disciplines in v1.

## Differentiation

The differentiator is not "better chat."
The differentiator is:

- verified references
- workflow provenance
- reporting-guideline awareness
- release packaging and citation support
- local-first defaults for unpublished work
