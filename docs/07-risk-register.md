# Risk Register

## Risk: fake or broken citations
**Impact:** catastrophic to academic trust  
**Mitigation:** hard identifier validation, no free-text bibliography invention

## Risk: attractive but irreproducible outputs
**Impact:** severe  
**Mitigation:** provenance manifests, rerun commands, clean-environment benchmarks

## Risk: scope explosion
**Impact:** severe  
**Mitigation:** biomedical PhD focus only for v1

## Risk: doc drift
**Impact:** medium-high  
**Mitigation:** Codex doc-sync skill, source-of-truth plan files, release gates

## Risk: insecure handling of unpublished work
**Impact:** severe  
**Mitigation:** local-first defaults, explicit network boundaries, security review

## Risk: software paper submitted too early
**Impact:** medium  
**Mitigation:** require exemplars, benchmarks, and external rerun evidence before submission
