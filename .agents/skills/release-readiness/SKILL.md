# release-readiness

## Trigger

Use this skill when preparing:
- GitHub releases
- DOI archiving
- software-paper submission
- public launch announcements

## Checklist

- citation metadata present and current
- changelog updated
- CODEOWNERS and SECURITY baseline present
- docs reflect actual implementation
- benchmarks and exemplars named consistently
- release version consistent across files
- archive metadata prepared
- AI usage disclosure status known for paper materials

## Output contract

Return:
- release blocker list
- warnings
- recommended tag readiness decision
