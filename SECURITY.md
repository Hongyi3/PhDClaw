# Security Policy

## Scope

This project is intended for local-first academic and bioinformatics workflows. Treat unpublished research data, credentials, and reviewer materials as sensitive.

## Reporting a vulnerability

Please report security issues privately to the maintainers listed in `CODEOWNERS` or the repository security contact once configured.

Do not open public issues for exploitable vulnerabilities before a fix is available.

## Security priorities

- workspace-scoped file access
- no hidden network behavior
- pinned dependencies where practical
- explicit disclosure of external services
- auditable release artifacts
- safe defaults for unpublished work
