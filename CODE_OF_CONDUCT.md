# Code of Conduct

This project is intended to be a welcoming, rigorous, and respectful space for research software contributors.

## Our expectations

Contributors are expected to:

- be respectful and constructive
- critique ideas and implementations, not people
- document decisions clearly
- keep scientific claims evidence-grounded
- disclose uncertainty honestly
- prioritize user safety, reproducibility, and academic integrity

## Unacceptable behavior

- harassment or discrimination
- abusive or insulting language
- intentionally misleading scientific or software claims
- plagiarism, citation fabrication, or data falsification
- sharing secrets, sensitive unpublished data, or private reviewer materials without permission

## Enforcement

Project maintainers may remove, edit, or reject contributions that violate this code of conduct.
