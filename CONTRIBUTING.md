# Contributing

Thank you for contributing to ClawBio Scholar.

## What we are building

ClawBio Scholar is intended to become scholarly infrastructure for biomedical PhD workflows. Contributions should improve one or more of the following:

- evidence integrity
- reproducibility
- reporting completeness
- manuscript quality
- release quality
- usability for serious academic work

## Before opening a pull request

1. Read `README.md`
2. Read `AGENTS.md`
3. Read `plans/master-plan.md`
4. Check whether the change matches current scope
5. Prefer opening or linking an issue first for non-trivial work

## Pull request expectations

Each pull request should:

- solve one coherent problem
- explain why the change matters
- update relevant docs
- include validation or tests where appropriate
- avoid expanding scope beyond the linked issue

## Good first contributions

- improve schema definitions
- add missing docs or fix doc drift
- improve Quarto templates
- add reporting-guideline coverage
- improve provenance checks
- expand benchmark fixtures

## What not to contribute first

Please do not begin with:

- large UI rewrites
- broad discipline expansion beyond biomedical research
- undocumented framework migrations
- features that generate prose without evidence checks

## Scientific integrity rules

- no fake references
- no unsupported results claims
- no benchmark cherry-picking
- no unlabeled synthetic examples presented as real evidence

## Style

- prefer explicit, readable code
- keep public docs professional and citation-aware
- use plain text artifacts when possible
- document decisions with enough detail for a future maintainer to reconstruct intent
